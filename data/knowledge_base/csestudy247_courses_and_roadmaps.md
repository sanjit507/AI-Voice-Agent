# CSE Study247 Courses, Tech Tutorials & Learning Roadmaps

## 1. Web Development & Full-Stack Roadmaps
- **Frontend Track**: HTML5, CSS3, Modern JavaScript (ES6+), responsive design, and React basics.
- **Backend Track**: Python with FastAPI, Node.js, RESTful API architecture, and SQLite/PostgreSQL databases.
- **Hands-on Projects**: Building portfolio projects, blog platforms, and e-commerce demo applications.

---

## 2. Artificial Intelligence, Data Science & Voice Agents Track
- **Python for Data Science**: NumPy, Pandas, Matplotlib, Data visualization.
- **Machine Learning & Deep Learning**: Scikit-Learn, PyTorch fundamentals, neural networks.
- **Generative AI & LLMs**:
  - Prompt Engineering and context management
  - Retrieval-Augmented Generation (RAG) architecture
  - LangChain and LangGraph for multi-agent workflows
  - LLM Fine-Tuning basics
  - Model Context Protocol (MCP) concepts
- **Real-Time Voice AI**:
  - Voice pipelines with Pipecat
  - Google Gemini Live API native audio streaming
  - WebRTC transport, Silero VAD turn detection, and interruption handling.
